# Настройка Supabase для TaskAI

## Проблема
Приложение не может подключиться к Supabase из-за отсутствия переменных окружения.

## Решение

### 1. Создайте файл .env в корне проекта
Создайте файл `.env` в корневой папке проекта со следующим содержимым:

```env
# Supabase Configuration
VITE_SUPABASE_URL=your_supabase_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here

# OpenRouter Configuration
VITE_OPENROUTER_API_KEY=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
VITE_OPENROUTER_MODEL=meta-llama/llama-3.1-8b-instruct:free
```

### 2. Получите данные Supabase
1. Зайдите на https://supabase.com
2. Войдите в свой аккаунт
3. Выберите проект или создайте новый
4. Перейдите в Settings → API
5. Скопируйте:
   - Project URL (замените `your_supabase_url_here`)
   - Project API keys → anon public (замените `your_supabase_anon_key_here`)

### 3. Создайте таблицу tasks
В Supabase SQL Editor выполните:

```sql
CREATE TABLE tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  description text,
  completed boolean not null default false,
  priority text check (priority in ('low','medium','high')) default 'medium',
  category text default 'Личное',
  due_date timestamptz,
  created_at timestamptz not null default now(),
  subtasks text,
  plan text
);

-- Включите RLS (Row Level Security)
ALTER TABLE tasks ENABLE ROW LEVEL SECURITY;

-- Создайте политику для всех пользователей
CREATE POLICY "Enable all operations for all users" ON tasks
FOR ALL USING (true);
```

### 4. Перезапустите сервер разработки
```bash
npm run dev
```

## Проверка
После настройки:
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Не должно быть ошибок "Supabase env variables are not set"
4. Приложение должно загружать задачи из базы данных
