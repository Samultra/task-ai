# TaskAI

🧠 ИИ-помощник для эффективного планирования дел, напоминаний и советов по тайм-менеджменту.

## Особенности

- ✅ Управление задачами с приоритетами
- ✅ Категоризация задач
- ✅ Статистика выполнения
- ✅ Адаптивный дизайн
- ✅ Локальное хранение данных
- ✅ ИИ-помощник (требует настройки Supabase)

## Демо

Сайт доступен по адресу: https://samultra.github.io/task-ai/

## Установка

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Для полной функциональности настройте Supabase (см. `SUPABASE_SETUP_INSTRUCTIONS.md`)

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Supabase (опционально)
- OpenRouter API (опционально)
